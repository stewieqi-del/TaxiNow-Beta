# TaxiNow Pro Beta

TaxiNow Pro 社区测试版，由 stewieqi-del 维护，基于 Sky Ning 的 TaxiNow Pro。仅供模拟飞行，不用于真实飞行；不是官方正式版渠道。

## 下载与更新

暂未发布首个安装包。首次安装请从本仓库 Releases 下载 Windows x64 安装器。安装 Beta 后，后续版本可在软件内提示更新，查看日志并点击下载安装；不是静默强制更新，也不是实时推送。

Beta 使用独立安装和默认数据目录，升级保留 Beta 地图、航图和设置。正式版不会接收本仓库更新，请勿同时运行两版。

## 发布约定

发布为非草稿的 Pre-release，每次递增 Build。安装包名为 TaxiNow-Pro-Beta-V2.0-Build-N-Setup.exe，并需要 GitHub asset 的 SHA-256 digest。单独 ZIP 不支持软件内安装。SHA-256 校验不等同于代码签名。

此仓库只保存版本说明及 Release 附件。源码开发位于 https://github.com/stewieqi-del/TaxiNow-Stewie 。不得提交令牌、个人配置或下载航图。

## Testing limitations

Community Beta, simulation only. ATIS and weather coverage/freshness vary. In-app updates require a first Beta installation and a later valid prerelease installer. No software release has been published yet.
